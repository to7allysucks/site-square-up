Multi-page website layout built as a practical training assignment.

Based on a [Figma prototype](https://www.figma.com/proto/5pU01xmfp6UKo8myiXhFn6).

## Installation

Requires **Node.js ≥ 20**

```bash
git clone https://github.com/to7allysucks/site-square-up.git
cd site-square-up

npm install

npm run dev    # dev server with live reload
npm run build  # production build bundle → dist/
```
